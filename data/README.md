# Evidence Data

This directory contains machine-readable records supporting the frozen evidence map used in the review.

The manuscript evidence cutoff is **3 August 2026**. The frozen corpus contains **42 primary study families**.

The file [`frozen_evidence_map_2026-08-03.csv`](frozen_evidence_map_2026-08-03.csv) records the family-level application domain, evidence codes, system taxonomy, methodological-concern profile, and principal limitation used in the review.

Post-cutoff literature is maintained separately and does not automatically modify this frozen evidence map.
