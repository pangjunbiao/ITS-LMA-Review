## Aggregate Evidence Profile

Across the **17 autonomous-driving study families**:

- **Capability:** C0 / C1 / C2 / C3 = **6 / 2 / 1 / 8**
- **Validation:** E1 / E2 / E3 / E4 = **7 / 9 / 1 / 0**
- **P1:** D / P / N = **12 / 5 / 0**
- **P2:** D / P / N = **0 / 4 / 13**
- **P3:** D / P / N = **15 / 2 / 0**

The domain therefore provides the strongest concentration of direct evidence in the review for **transportation semantics (P1)** and **multidimensional transportation integration (P3)**, but evidence for explicit source reconciliation and provenance handling (P2) remains substantially weaker.

Eight families demonstrate **C3 outcome-responsive capability**, but most of this evidence remains at **E2 interactive simulation**. Only one family reaches **E3 controlled real-world evidence**, and no family reaches **E4 sustained deployment evidence**.

The evidence supports roles such as semantic scene interpretation, intent and rule grounding, high-level planning, explanation, memory-supported reasoning, and specialist-tool coordination. It does not establish unrestricted low-level control authority, sustained operational deployment, or replacement of independently verifiable perception, planning, control, monitoring, and fallback functions.

For the complete family-level taxonomy, Q1–Q8 methodological-concern profile, and principal limitations, see the [frozen evidence map](../data/frozen_evidence_map_2026-08-03.csv).

### Coding Note

C, E, and P labels are analytical classifications assigned in the review rather than labels used by the original study authors. Definitions are provided in the [ITS-LMA evidence framework and taxonomy](../taxonomy.md).

The application-domain assignment follows each study family's **principal evaluated foundation-model role**, not simply the wording of the paper title.
